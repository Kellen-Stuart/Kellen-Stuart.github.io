# Changes wanted to /jam
Overview of all the changes I want the agent to make to the /jam route.

## Difficulty Tag
1-10 difficulty turns out to be less useful than I thought. I think simplifying it to "Easy" "Medium" "Hard" is a good quick way for me to categorize a song quickly in a jam setting. The overall goal of this page is to help me quickly select songs in a jam.

Make "Easy" Green
Make "Medium" Yellow
Make "Hard" Red

## Remove "Key" Tag
Tagging the Key is not useful. I find it useful on the actual card itself but not as a tag you can filter by. It makes it difficult to actually read through all the filters so this is a good QoL to clean this up. Keep it in the card though, it's useful to know what key the song is in.
